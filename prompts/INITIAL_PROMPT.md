# Initialer Prompt für den OMO-Implementer

Klone dieses Repository und arbeite den Auftrag vollständig ab:

```bash
git clone <REPOSITORY-URL>
cd qwen38-variant-b-architecture
```

Lies danach zuerst `AGENTS.md` und anschließend `tasks/MASTER-AUFTRAG-VARIANTE-B.md`. Setze die dort geforderten Recherche-, Architektur-, Implementierungs- und Testphasen strikt in kleinen, überprüfbaren Schritten um. Beginne mit der Quellenprüfung und der Machbarkeitsentscheidung für NVIDIA FP4-Local plus selektives ThinkingCap-Overlay. Verändere keine produktiven Repositories oder Hardwarekonfigurationen, bevor die jeweilige Phase ihre Tests und Abnahmekriterien erfüllt. Dokumentiere jede Entscheidung, jeden Test, jede Unsicherheit und jeden Commit im Repository.
