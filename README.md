# Qwen 3.8 Flash-Next – Variante B Architekturpaket

Dieses Repository enthält die von einem Principal-Architect-Recherchepaket abgeleitete Blaupause für Variante B: NVIDIA Qwen3.8-Flash-Next-FP4-Local, Pennyroyal-Basis, selektive Hyperburst-Patches, optionales Lesilva-NVFP4-QSA-KV, Streaming-HiCache/NIXL und kontrolliertes ThinkingCap-Overlay.

## Start

1. `00_START_HERE.md` lesen.
2. `AGENTS.md` lesen.
3. `01_EXECUTIVE_SUMMARY.md` bis `12_DEPLOYMENT_ROLLBACK.md` lesen.
4. Phase 00 aus `08_IMPLEMENTATION_ROADMAP.md` und `prompts/PHASE-00.md` ausführen.
5. Erst nach dem Gate mit der nächsten Phase fortfahren.

Das Repository enthält keine Modellgewichte. Gewichte und generierte Hybrid-Checkpoints liegen außerhalb Git und werden über SHA256-Manifeste referenziert.
