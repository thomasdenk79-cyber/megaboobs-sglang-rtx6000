# Qwen 3.8 Flash-Next – Variante B Architekturpaket

Dieses Repository enthält das vollständige Architektur- und Implementierungspaket für Variante B: NVIDIA Qwen3.8-Flash-Next-FP4-Local mit selektivem ThinkingCap-Overlay, Hyperburst-/Pennyroyal-Integration, Lesilva-NVFP4-QSA-KV und SSD-HiCache/NIXL.

## Start

1. `AGENTS.md` lesen.
2. `tasks/MASTER-AUFTRAG-VARIANTE-B.md` vollständig lesen.
3. Den Auftrag in atomare Phasen zerlegen und vor jeder Implementierung die Quellen, Commits und Kompatibilität prüfen.
4. Jede Änderung mit Tests, Messwerten und Git-Commit dokumentieren.

Modellgewichte und proprietäre Artefakte gehören nicht in dieses Repository.
