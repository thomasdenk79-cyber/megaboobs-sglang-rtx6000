## Folder map

- `docs/`: research and architecture reports
- `prompts/`: coordinator, worker, and reviewer instructions
- `manifests/`: source, version, tensor, and acceptance metadata
- `diagrams/`: Mermaid architecture and sequence diagrams
- `tasks/`: original user requirements and phase folders
- `report/`: HTML navigation entry point
